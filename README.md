# Gallery Drift
Canvas visivo infinito per la galleria fotografica del dispositivo, derivato come esperienza da Art Drift.

## Stato
Repository inizializzato per conservare il progetto. Il codice Flutter/APK non è ancora stato importato o certificato in questo repository.

## Visione
- Visualizzazione immersiva delle immagini dalle sole cartelle selezionate dall'utente.
- Pan/zoom e layout infinito, preferiti, metadati ed eliminazione gestita dal sistema operativo.
- Componenti Flutter riutilizzabili con Art Drift, senza confondere il contenuto privato della galleria con i cataloghi pubblici d'arte.
